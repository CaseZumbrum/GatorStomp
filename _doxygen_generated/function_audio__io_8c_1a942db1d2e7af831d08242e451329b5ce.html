int audio_io_run(const AudioIOConfig *config, AudioProcessCallback process, void *user_data)

Run input, optional DSP processing, recording, and playback.

Uses blocking ALSA I/O, S24_3LE interleaved access, disabled software resampling, and a requested 100 ms device latency. Partial ALSA transfers are handled and recoverable ALSA errors are retried. File EOF must fall on a complete PCM frame. Diagnostics are printed to stderr and completion to stdout.

Run input, optional DSP processing, recording, and playback.

Allocates one block, handles short ALSA transfers, and releases opened resources on exit. Live capture has no built-in termination mechanism.

Warning

Live capture runs indefinitely: there is no cancellation API, pipe transport, or graceful signal shutdown. Recovery may lose audio; this API does not promise real-time scheduling, hardware support, or ADC/DAC verification. Outputs may be partial after failure. Input and output paths must refer to different files; opening the output truncates any existing contents.

Parameters:

  • config – Borrowed configuration with nonzero rate, channels, and block size. At least one input and one output must be configured. Must not be NULL.

  • process – Optional synchronous DSP callback; NULL passes PCM unchanged.

  • user_data – Borrowed callback context; may be NULL.

  • config – Borrowed file/device configuration.

  • process – Optional in-place DSP callback.

  • user_data – Opaque borrowed callback context.

Returns:

0 after successful input EOF and playback drain; -1 on invalid configuration, allocation, file I/O, or unrecoverable ALSA failure.

Returns:

0 on successful EOF and drain, -1 on failure.
