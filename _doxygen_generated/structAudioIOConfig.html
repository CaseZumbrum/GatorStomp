struct AudioIOConfig

Configuration borrowed for the duration of audio_io_run().

Set unused paths/device names to NULL. Input files take precedence over capture devices; playback and output-file recording may both be enabled. Paths, device strings, and this configuration must remain valid during the run.

Public Members

unsigned int sample_rate

Requested frames per second; must be nonzero. Tested at 96000.

unsigned int channels

Interleaved channel count; use 2 for stereo. Must be nonzero.

unsigned int frames_per_buffer

Maximum frames passed to the callback per block; must be nonzero.

const char *input_file

Raw PCM input path, or NULL to use capture_device.

const char *capture_device

ALSA capture device name, required when input_file is NULL.

const char *playback_device

Optional ALSA playback device name; NULL disables playback.

const char *output_file

Optional raw PCM output path, truncated on open.
