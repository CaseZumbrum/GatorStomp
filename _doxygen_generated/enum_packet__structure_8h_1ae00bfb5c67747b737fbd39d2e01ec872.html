enum gs_msg_type

Enum for the message type of a socket message, used to control which kind of message is being sent.

Values:

enumerator GS_MSG_ACK

acknowledgement message

enumerator GS_MSG_BUTTON

button press related message

enumerator GS_MSG_TWEAK

tweaking an effect parameter related message

enumerator GS_MSG_VOLUME

system volume related message message

enumerator GS_MSG_UNUSED

additional message type, not currently in use
