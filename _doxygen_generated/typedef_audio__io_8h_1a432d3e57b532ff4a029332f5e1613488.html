  • Defined in File audio_io.h

Typedef Documentation

typedef void (*AudioProcessCallback)(uint8_t *buffer, size_t frames, unsigned int channels, void *user_data)

DSP callback that modifies a PCM block in place, synchronously.

Note

Do not resize/free/retain buffer. Preserve the frame count and format. Blocking DSP work delays capture/playback and may cause overruns/underruns.

Param buffer:

Borrowed writable PCM bytes; valid only during the callback. Contains frames * channels * 3 bytes, not floating-point samples.

Param frames:

Number of complete frames, possibly less than frames_per_buffer.

Param channels:

Number of interleaved channels in each frame.

Param user_data:

Opaque caller data passed unchanged by audio_io_run().

Return:

No value; this callback cannot report a processing failure.
