class EchoEffect : public Effect

Class for the echo effect.

Public Functions

EchoEffect(unsigned int sample_rate = 44100, float delay_ms = 300.0f, float decay = 0.5f, float wet = 0.5f, float dry = 1.0f)

Constructor, initializes buffers and attributes.

Parameters:

  • sample_rate – sample rate for the signal, needed to accurately perform the echo delay (in Hz)

  • delay_ms – amount of time for a single delay pulse

  • decay – how much the echo should be scaled by

  • wet – how much the output should include delay

  • dry – how much the output should include the original
