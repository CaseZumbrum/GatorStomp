
Connecting to the PocketBeagle 2
================================

This guide explains how to flash the GatorStomp operating system onto
a microSD card, boot the PocketBeagle 2, and establish an SSH connection
over USB-C.

Prerequisites
-------------

Before starting, make sure you have:

- A **PocketBeagle 2** development board
- A microSD card and USB microSD card reader
- A **data-capable USB-C cable**
- A Windows, Linux, or macOS computer
- The latest GatorStomp Yocto image (``.wic`` or ``.wic.xz``)


Step 1: Download the Imaging Utility
------------------------------------

Insert the microSD card into your computer using a card reader.

Download and install the official
`BeagleBoard Imaging Utility <https://www.beagleboard.org/bb-imager>`_.

Launch the application after installation.


Step 2: Configure the Imaging Utility
-------------------------------------

Select the following settings to prepare the GatorStomp operating system.

Hardware
~~~~~~~~

Select **PocketBeagle 2** as the target device.

Software
~~~~~~~~

1. Click **Select Local Image**.
2. Choose the ``.wic`` or ``.wic.xz`` image generated by the latest
   Yocto build. You can also obtain a prebuilt image from the
   GatorStomp GitHub Releases page.
3. Select ``sysconfig`` as the Init Format, if prompted.

.. note::

   GatorStomp's custom Yocto image already contains its own startup
   and SSH configuration. Selecting ``sysconfig`` in the imager does
   not configure those services.

Storage
~~~~~~~

Select the microSD card as the destination drive.

.. warning::

   Double-check your selection. Flashing will erase the existing
   contents of the selected drive.

Modify
~~~~~~

Leave the customization options unchanged.

The current GatorStomp development image already includes:

- USB networking using NCM
- Automatic IP address assignment using DHCP
- Dropbear SSH server
- Root SSH access without a password

.. warning::

   **Security notice:** Passwordless root access is intended for
   the development image only. Proper authentication must be
   configured before production use.

Write
~~~~~

Click **Write** to begin flashing the operating system.

Wait until the imaging utility completes the process.

.. important::

   **Windows disk formatting warning**

   Windows may ask you to format the microSD card after flashing.

   **Do not format it!**

   The GatorStomp image contains Linux partitions that Windows may
   not recognize. This is expected. Dismiss the formatting prompt.


Step 3: Boot the PocketBeagle 2
-------------------------------

1. Safely eject the microSD card from your computer.
2. Insert it into the PocketBeagle 2's microSD card slot.
3. Connect the PocketBeagle 2 to your computer using a
   **data-capable USB-C cable**.
4. Allow the board to complete its boot process.

The green status LEDs should show activity while the device is running.

The GatorStomp operating system automatically configures USB networking,
allowing your computer to communicate with the board.

.. note::

   On Windows, the board should appear as a USB Ethernet adapter,
   commonly identified as **UsbNcm Host Device**.


Step 4: Connect via SSH
-----------------------

Open a terminal on your computer.

On Windows, you can use **PowerShell**, **Windows Terminal**, or
**Git Bash**.

Enter:

.. code-block:: console

   ssh root@192.168.7.2

The PocketBeagle 2 uses the fixed IP address ``192.168.7.2`` for
USB networking.

The built-in DHCP server automatically assigns a compatible IP
address to your computer, so no manual network configuration should
be necessary.

If this is your first connection, SSH may ask you to confirm the
device's host key. Verify that you are connecting to your intended
board before accepting it.

Once connected, you should see a terminal prompt similar to:

.. code-block:: console

   root@pocketbeagle2:~#

**Huzzah! You're now inside the GatorStomp operating system!**


Step 5: Verify the Connection
-----------------------------

To verify that you're running Linux on the physical PocketBeagle 2,
execute:

.. code-block:: console

   uname -a

This displays the kernel version and hardware architecture.

You can also view the USB networking startup log:

.. code-block:: console

   cat /home/root/gatorstomp-usb-debug.log

This log records USB gadget initialization and DHCP activity
for debugging.


Troubleshooting
---------------

The computer does not recognize the PocketBeagle 2
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Make sure your USB-C cable supports **data transfer**, not just
  charging.
- Try another cable or USB port.
- Check Windows Device Manager for **UsbNcm Host Device**.
- Ensure the microSD card is properly inserted.


SSH connection times out
~~~~~~~~~~~~~~~~~~~~~~~~

First, check whether the board responds:

.. code-block:: console

   ping 192.168.7.2

If the ping fails, confirm that your computer received an IP address
on the ``192.168.7.x`` subnet.

On Windows, use:

.. code-block:: console

   ipconfig

Find the USB Ethernet adapter and inspect its IPv4 address.


SSH reports that the remote host identification has changed
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This can happen when switching between the official Debian image
and GatorStomp, or after reflashing the board.

If you have verified that you're connecting to your own PocketBeagle 2,
remove the previously saved host key:

.. code-block:: console

   ssh-keygen -R 192.168.7.2

Then reconnect:

.. code-block:: console

   ssh root@192.168.7.2

Verify and accept the new host key when prompted.
