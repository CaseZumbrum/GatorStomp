Detailed Description
--------------------

One reader and one writer per FIFO. All PCM is 96000 Hz, stereo, signed packed 24-bit little-endian: six bytes per interleaved frame. These helpers never create FIFOs, launch processes, or install signal handlers. Callers own/close returned descriptors and choose their own SIGPIPE policy. A stop pointer may be NULL, or point to a caller-owned signal-safe flag that stays valid throughout the call. Workers use it for SIGINT/SIGTERM shutdown.
